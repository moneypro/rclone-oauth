RCLONE

This is a privately operated Google Drive synchronization setup using the open-source rclone application. It synchronizes files between Google Drive accounts authorized by their users and storage managed by the operator.

Google Drive access allows rclone to list, download, upload, update, and delete files as needed for the configured synchronization tasks. This setup is intended for the operator and authorized account users, and is not a public sign-up service.

This page describes this particular setup and is not the official rclone project website.
